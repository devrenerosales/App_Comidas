# Verificación de HU-32 — Compartir la lista

Fecha: 2026-11-05. Implementación local para revisión del PO. Supuestos de CU-07.5 aplicados: por defecto se comparten
solo los productos pendientes y los precios no se incluyen en el texto. Es una historia solo de la app: no requiere
cambios en la API ni migraciones.

## Alcance verificado

- **`@menu/shared`**: `textoDeLista` (encabezado con las fechas, una línea por producto, pendientes o todos) y
  `cantidadDeCompra`, que antes vivía dentro de la pantalla Lista y ahora la usan la pantalla y el texto.
- **Pantalla Lista**: botón **Compartir** con la casilla **Incluir comprados**. Abre el menú de compartir del
  navegador (Web Share); si no existe copia el texto ("Lista copiada"); si tampoco puede copiar muestra el texto para
  copiarlo a mano.

También: 1a incluir comprados (con "Ya lo tengo" incluido), que los precios no salgan en el texto, cerrar el menú de
compartir sin que pase nada más, un fallo de compartir que se resuelve copiando, y el texto manual cuando no se puede
copiar.

## Interpretaciones para el PO

1. **Agrupación:** el texto sigue el orden de la lista, que hoy es plano. Cuando HU-31 agrupe por supermercado, el
   texto debe seguir esa agrupación ("agrupados como en la vista actual").
2. **"Incluir comprados":** suma también los productos marcados "Ya lo tengo", porque la historia pide "todos los
   productos".
3. **Productos de la despensa y manuales:** se comparten igual que los demás; el texto no distingue el origen.
4. **Ruta del servidor:** `GET /listas/{id}/texto` queda sin implementar, porque la app lo arma sola y así funciona sin
   conexión.

## Límites

- No se probó en un navegador real ni en Android.
- **Capacitor Share no está instalado:** se usa la Web Share API del navegador, que en una PWA móvil abre el menú del
  sistema. Si la app se empaqueta para Android con Capacitor, hay que validar ese menú o agregar `@capacitor/share`.
- El navegador de escritorio de Windows y Mac suele ofrecer compartir solo con HTTPS; en `localhost` y con otros
  navegadores se usará la copia al portapapeles.
- El texto no incluye enlace a la app.

## Validación manual propuesta

Abrir **Lista** con una semana aprobada, marcar un par de productos como comprados y tocar **Compartir**. En el teléfono,
elegir WhatsApp y comprobar el mensaje; en el navegador de escritorio, pegar el texto copiado en un chat o un bloc de
notas. Probar **Incluir comprados**, y marcar todo como comprado para ver "No hay productos pendientes". Repetir con el
modo sin conexión del navegador activado.
